Analisis de la peticion al servidor
URL solicitada: http://127.0.0.1:5500/index.html
Respuesta observada anteriormente: 403 Forbidden. El servidor encontro el recurso, pero denego el acceso; no es un error 404 de ruta inexistente.
Al navegar, el navegador solicita cada documento y sus recursos al servidor. Una respuesta 2xx indica exito; 403 indica acceso prohibido y 404 indica que la ruta no existe.

Roles de las tecnologias
HTML define la estructura y el contenido semantico de las paginas.
CSS controla la presentacion visual, como colores, espaciado y tipografia.
JavaScript agrega comportamiento e interactividad; estas paginas no lo necesitan para navegar entre ellas.
